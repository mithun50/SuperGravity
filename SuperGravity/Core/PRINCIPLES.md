# SuperGravity Core Principles

> **Framework Note**: These principles guide all SuperGravity agents and commands in Google Antigravity IDE.

## Core Philosophy

SuperGravity transforms Google Antigravity into a predictable, structured development platform through behavioral injection and intelligent agent coordination.

## Foundational Principles

### 1. Agent-First Development
- Embrace Antigravity's agent-first architecture
- Let agents plan, execute, and verify autonomously
- Intervene only at critical decision points
- Trust artifacts over raw logs

### 2. Artifact-Driven Verification
- Every significant action produces verifiable artifacts
- Screenshots, recordings, diffs prove completed work
- Implementation plans precede major changes
- Task lists track progress transparently

### 3. Three-Surface Orchestration
- **Editor**: Code generation, refactoring, analysis
- **Terminal**: Commands, builds, database operations
- **Browser**: Testing, visual verification, scraping
- Use the right surface for each task

### 4. Progressive Autonomy
- **Secure Mode**: Maximum human oversight
- **Review-Driven**: Pause at checkpoints
- **Agent-Driven**: Full autonomy within bounds
- Configure per-task based on risk

### 5. Knowledge Persistence
- Build project knowledge bases
- Save successful patterns for reuse
- Learn from session to session
- Share knowledge across workspaces

## Quality Standards

### Code Quality
- No placeholder content in production
- Error handling is mandatory
- Type safety where possible
- Tests accompany new code

### Security Standards
- Zero trust by default
- Validate all inputs
- No hardcoded secrets
- Follow OWASP guidelines

### Performance Standards
- Measure before optimizing
- Set performance budgets
- Profile, don't guess
- Document trade-offs

## Integration Philosophy

### With Gemini Models
- Leverage 1M token context wisely
- Use Deep Think for complex problems
- Switch models based on task needs
- Optimize tokens when appropriate

### With MCP Servers
- Use Context7 for documentation
- Use Sequential for reasoning
- Use Magic for UI generation
- Handle failures gracefully
