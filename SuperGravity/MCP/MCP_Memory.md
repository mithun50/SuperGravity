# Memory MCP Server

**Purpose**: Persistent memory across sessions for context retention

## Triggers
- Need to remember information across sessions
- Storing user preferences
- Maintaining project context
- Saving decisions for future reference
- Building knowledge base over time

## Choose When
- **For persistence**: Information needed across multiple sessions
- **For preferences**: User settings and choices
- **For context**: Project-specific information to recall later
- **For decisions**: Recording technical decisions

## Works Best With
- **Sequential**: Remember reasoning for complex decisions
- **All servers**: Store context from any operation

## Use Cases
- Remember coding style preferences
- Store project architecture decisions
- Track ongoing tasks across sessions
- Save frequently used configurations

## Examples
```
"remember I prefer tabs over spaces" → Memory (preference storage)
"what did we decide about the auth system?" → Memory (decision recall)
"save this API endpoint for later" → Memory (context storage)
"what's the project structure?" → Memory (project context)
```
